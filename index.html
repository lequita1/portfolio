Web applicationGame discovery

Game Vault.

Less searching.
More discovering.

A React game browser powered by the RAWG API. Search for games, explore genres, and browse a visual catalog with artwork, ratings, and release years—all in one place.

  • React
  • RAWG API
How it works — Game Vault

What it does

Game Vault makes a large game catalog easier to explore. Visitors can search by name, narrow the catalog with genre filters such as Action, RPG, and Adventure, and use the sorting control to change how games are displayed. Each card brings together a game’s cover image, title, rating, and release year.

How it’s built

React handles the interface and presents the game information as cards. The RAWG API supplies the game data through requests authenticated with an API key. The app brings that external information into a consistent browsing interface instead of maintaining its own game database.

The idea behind it

Make discovering a game feel straightforward: a clear search field, easy-to-find filters, and enough information on each card to decide what deserves a closer look.

Eggscavator.

One egg.
More than one ending.

A game made in Roblox Studio where breaking an egg leads to different endings and cutscenes. Unlock new chapters and discover more of the story as you play.

  • Roblox Studio
  • Cutscenes
  • Chapters
How it works — Eggscavator

What you do

The central interaction is simple: break an egg and discover what happens. Different endings and cutscenes turn that small action into a story to explore, while unlockable chapters give players more to discover.

How it’s built

Eggscavator is made in Roblox Studio. The game combines a playable 3D environment with egg-breaking interactions, story cutscenes, and chapter progression. The screenshot shows the game world, including its plaza, paths, trees, and mountain surroundings.

The idea behind it

Use a familiar action as the beginning of something unexpected. The different outcomes and chapters give players a reason to stay curious about what comes next.

PawCare.

Their everyday care.
In one little app.

A simple pet-care app built with Flutter and SQLite. Keep pet profiles, care reminders, and activity records together, with data stored locally so the app works offline.

  • Flutter
  • SQLite
  • Offline & local
How it works — PawCare

What it does

PawCare brings everyday pet care into a simple dashboard. It shows pet profiles, care reminders, daily progress, and activity records. Quick actions make it easy to add a pet, create a reminder, or log an activity, while overdue care is highlighted on the home screen.

How it’s built

Flutter provides the app’s interface, and SQLite stores its information directly on the device. The app is offline and local: its pet-care information can be used without an internet connection and stays in the device’s local database.

The idea behind it

Give pet owners one place to keep track of the small things that matter, from care schedules to everyday activities, with a clear view of what needs attention next.
