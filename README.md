# My Portfolio

My personal portfolio, built with HTML, CSS, and JavaScript. It includes a short introduction, my projects, and my contact details.

## Projects

### Game Vault

A game browser I made with React and the RAWG API. You can search for games, filter by genre, and sort the results. The game cards show artwork, ratings, and release years.

### Eggscavator

A Roblox game made in Roblox Studio. You break an egg to discover different endings and cutscenes, then unlock more chapters as you play.

### PawCare

A simple pet-care app made with Flutter and SQLite. It keeps pet profiles, reminders, and activity records on the device and works offline.

## Portfolio features

- Dark and light mode
- Mobile navigation menu
- Expandable project descriptions
- Full-size screenshots
- Email, GitHub, and LinkedIn links with icons
- Copy email button

## Running it

Open `index.html` in a browser. There’s nothing to install.

The copy email button needs localhost or HTTPS. The email link still works when you open the file directly.

## Files

- `index.html` — page content
- `style.css` — styling and mobile layout
- `script.js` — theme toggle, menu, and email copying
- `mypicture.jpg` — my photo
- `assets/projects/` — project screenshots
- `assets/favicon.svg` — site icon

To change the project descriptions, edit `index.html`. To replace a screenshot, update its image in `assets/projects/`.

## GitHub Pages

Upload the files to a public GitHub repository. In **Settings → Pages**, choose the branch and its root folder, then save.
